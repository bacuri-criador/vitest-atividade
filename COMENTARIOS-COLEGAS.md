# Sugestões de comentários para colegas

Personalize os comentários de acordo com o projeto de cada colega.

## Comentário 1
Gostei da separação entre as rotas e as regras de negócio. Isso deixa o projeto mais organizado. Uma melhoria interessante seria incluir testes para dados inválidos e para situações em que o registro não é encontrado.

## Comentário 2
Achei interessante a forma como os testes verificam as respostas da API. O uso de mocks também é uma boa prática para isolar os testes. Como melhoria, sugiro testar os possíveis erros do banco de dados e adicionar um relatório de cobertura.
